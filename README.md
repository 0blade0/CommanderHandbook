# Commander's Handbook (Довідник командира)

**Курсовий проєкт з дисципліни «Об'єктно-орієнтоване програмування»**  
**Студент:** Алєксєєв Ілля  
**Навчальний заклад:** Харківський національний університет радіоелектроніки (ХНУРЕ)
**Група:** ПЗПІ-25-3

---

## Опис проєкту
Інформаційна система для управління обліком особового складу підрозділу. Програма дозволяє систематизувати дані про офіцерів та військовослужбовців строкової служби, забезпечуючи зручне управління даними.

## Технологічний стек
* **Мова:** C# / .NET 10.0
* **Платформа:** Windows Forms (WinForms)

## Основні функції
- [x] Відображення загального списку підрозділу.
- [x] Фільтрація за категоріями (Офіцери / Строковики).
- [x] Автоматичне сортування за алфавітом (прізвище).
- [x] Видалення записів (через Delete).
- [x] Живий пошук за прізвищем.
- [x] Додавання нових бійців.
- [x] Додаткова інформація по бійцю.
- [x] Громадянська професія бійця.
- [x] Посада бійця.
